"Scraps" - The Recipe Recommendation Model

Give me ingredients and I'll give you a recipe.

I made this when I first started cooking and had no idea what to make. It's a web app where you can enter ingredients you have lying around the kitchen, and it recommends recipes you can make. I built it using Python and Streamlit, and used Natural Language Processing to parse user input. The model uses Word2Vec to understand how ingredients relate to each other - giving smarter suggestions rather than just keyword matching.


Twitch Streamer Data Scraper & Analysis

What makes a streamer popular? I dug into Twitch data to find out.

Curious about what drives success on Twitch, I built a Python scraper using BeautifulSoup to collect real streamer stats directly from the site. From followers to peak viewers, I cleaned and analyzed the data in Jupyter Notebook, visualizing key relationships with pandas and seaborn. The insights revealed that a handful of streamers dominate the audience while most compete in smaller viewer groups — confirming what streamers talk about but with actual data. This project helped me sharpen web scraping, data cleaning, and exploratory visualization skills — all while exploring a personal interest in streaming.


Video Game Win Prediction Model

Based off of one of my favorite video games: Valorant.

This was my first ever project — I used a dataset from Kaggle to explore what factors actually led to winning in Valorant. I cleaned and transformed the player data, then built a predictive model in R to highlight which attributes had the biggest impact on win rates. I tried out multiple regression models (Linear, Decision Tree, Boosted Tree, and Random Forest) and used ggplot2 to visualize key patterns. It was my intro to data science, and I wanted to tie in a personal interest to have fun while exploring a new field that I ended up really enjoying.
